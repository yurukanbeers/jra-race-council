# ChatGPTで競馬予想会議を開いてみた。4人のAIはどこを見る？

おつかんでーす♪(^^)o∀∀o(^^*)♪🍻✨

競馬初心者の私ですが、馬券を考えていると、毎回どこかで手が止まります。

「この馬、強そうだけど1頭軸で大丈夫？」  
「相手を増やしたいけど、1点だけ当たっても予算を回収できる？」  
「この穴馬、買う理由があるのか、配当を見て欲しくなっただけなのか？🙃」

こういう疑問をひとつずつ検討できたら面白そう。ということで、**ChatGPTの中で競馬予想会議を開くプロンプト**を作ってみました。

名前は **JRA Race Council**。JRAのGⅠ・GⅡを対象に、レース名と予算を伝えると使えます🏇

## 4人の専門担当と議長で予想する

| 担当 | 何を見るか |
|---|---|
| **A｜実力・適性** | 過去走、対戦相手、斤量、コース実績から、勝ち切れそうな馬と3着以内に入りそうな馬を探す |
| **B｜展開・馬場** | 枠順、先行争い、天気や馬場から、どの馬に展開が向きそうかを考える |
| **C｜反証・穴馬** | 人気馬が崩れる条件と、人気薄を買い目に残す根拠を探す |
| **D｜馬券・資金配分** | オッズと予算から券種・買い目・金額を組み立て、的中時の収支や軸が外れた場合を確認する |
| **議長｜進行・結論・再点検** | 意見が割れた点を検証し、着順と馬券案をまとめる。最後に、何が変わったら予想を見直すかを確認する |

まずA〜Cがそれぞれ予想を出し、意見を突き合わせます。議論は基本3ラウンドで、追加で確認すべき論点があれば最大10ラウンド。**どこで意見が割れ、何を根拠に結論が変わったか**も、ラウンドごとに読めるようにしました。

着順が決まったら、Dが馬券を考えます。**「上位3頭を当てるならこの3頭」と「3,000円で買うならこの組み合わせ」**は、それぞれ答えを出します。上位に来そうな馬同士でも、オッズ次第でその買い目にいくら使うかは変わるからです。

## 前日に予想して、当日に同じチャットで見直せます

前日に一度予想を出して、開催当日は同じチャットで**「当日版を出して」**と頼めます。レースと予算を引き継ぎ、当日の馬場、天気、馬体重、オッズなどを確認してから、前日と比べて何を変えたか、その理由を出します。

予想を読んで「この馬、前残りなら来そうじゃない？」「この軸に寄りすぎてない？」と思ったら、そのまま聞いてみてください。根拠を確認したうえで、着順予想や買い目に影響するかを検討します。結論を変えるときも、維持するときも、理由を聞けます。

## 使い方

1. 公開ページの**「起動メッセージをコピー」**を押す。
2. ChatGPTに貼り付けて送信する。おすすめは**Workモード**です。
3. 聞かれたら「マイルCS、予算3,000円前後」のように答える。

通常のChatでも使えます。独立したエージェントを起動できない環境では、同じチャット内で4つの視点から検討します。

[JRA Race Councilを開く](https://yurukanbeers.github.io/jra-race-council/)

予想が当たったらもちろんうれしい。でも、レース後に「あの馬、なんで切ったんだっけ？」となることが多い私には、**買う前に何を考えたか残せる**のが、いちばん気に入っているところです。

使ってみて「この観点も入れたら面白そう」というのがあれば、ぜひ教えてください🏇✨
